## Picture Management System

### Tech Stack
- Photo storage - OneDrive
- Database - PostgreSQL
- Backend - Python + FastAPI
- ORM - SQLAlchemy
- Migrations - Alembic
- OneDrive access - Microsoft Graph API
- Frontend - React or Next.js
- Metadata extraction - Pillow + ExifRead
- Containers — Docker
